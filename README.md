# Comment.io workflow skills

Connect an agent to a Comment.io workspace using remote OAuth MCP at `https://comment.io/mcp` when your client supports it. A person in the workspace signs in and approves the agent. Ask the connected `run` tool to run `help`. See the [MCP guide](https://comment.io/llms/mcp.md), or the [agent guide](https://comment.io/llms.txt) for SSH and HTTP alternatives. For ongoing agent use, install the [using-commentio skill](https://comment.io/skills/using-commentio/SKILL.md). Support: [support@comment.io](mailto:support@comment.io).
