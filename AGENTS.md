# Comment.io workflow skills — agent instructions

For workspace access, connect a client that supports remote OAuth MCP to `https://comment.io/mcp` and follow the [MCP guide](https://comment.io/llms/mcp.md). A person in the workspace must approve the agent. Use the [live agent guide](https://comment.io/llms.txt) for SSH or HTTP alternatives and the [using-commentio skill](https://comment.io/skills/using-commentio/SKILL.md) for future sessions. Support: support@comment.io.

The published skills are in `skills/<name>/SKILL.md`; their behavior is generated from a separate source. Edit that source when changing skill behavior.
